# 平台运行与部署

这里维护 Another Atom 平台自身的运行步骤和部署约束。它不是生成项目的交付渠道，也不保存 Feature 产品规则。

- [运行与部署](./01-运行与部署.md)：本地启动、Railway CLI 查询、部署入口及操作边界；是否实际完成以环境证据为准。
- [部署组成与存储约束](./02-部署组成与存储约束.md)：主服务、执行服务、编辑沙箱与存储的既有约束。
- [环境登记规范](../agents/validation-environments.md)：本地登记的读取约定、字段模板、版本读回和授权边界；真实环境清单不随仓库提交。

生成项目的版本与线上交付归 [Feature 12](../features/05-产物与交付部署/12-版本预览与发布/README.md)，运行能力归 [Feature 07](../features/05-产物与交付部署/07-通用源码与运行校验/README.md)。操作说明不是部署授权；实际环境身份和带日期的只读核对结果以本地登记为准，不能由文档存在推定功能验证完成。
