# 平台运行与部署

这里维护 Another Atom 平台自身的运行步骤和部署约束。它不是生成项目的交付渠道，也不保存 Feature 产品规则。

- [运行与部署](./01-运行与部署.md)：启动、配置及部署检查步骤；是否实际完成以环境证据为准。
- [部署组成与存储约束](./02-部署组成与存储约束.md)：主服务、执行服务、编辑沙箱与存储的既有约束。
- [环境登记](../agents/validation-environments.md)：实际环境、不可变版本、授权与验证入口。

生成项目的版本与线上交付归 [Feature 12](../features/05-产物与交付部署/12-版本预览与发布/README.md)，运行能力归 [Feature 07](../features/05-产物与交付部署/07-通用源码与运行校验/README.md)。操作说明不是部署授权，本轮整理没有访问或修改线上环境。
