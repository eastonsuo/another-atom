# 整体设计概览

本目录只解释产品整体定位、主流程、组件关系与功能范围，不保存功能细则、接口字段、状态表、产品问答或实施合同。详细内容从 [Feature 索引](../features/README.md)进入。

| 概览 | 回答的问题 |
| --- | --- |
| [产品定位](./01-产品定位.md) | 产品服务什么目标，哪些原则持续保持 |
| [端到端流程](./02-端到端流程.md) | 各 Feature 如何组成首次创建和持续修改流程 |
| [系统架构概览](./03-系统架构概览.md) | 谁保存事实、谁生成产物、谁执行副作用 |
| [功能范围与整体验收](./04-功能范围与整体验收.md) | 各能力域的 Feature 归属、推进条件与完成口径 |

不再按产品版本分组或安排整版先后顺序。各 Feature 分别维护范围、依赖、确认、实现和验证状态。一个跨 Feature 合同由一个 Feature 维护，其他 Feature 只引用，不因跨域就搬到 design。

平台自身运行步骤在 [operations](../operations/README.md)，外部参考在 [references](../references/Atoms参考产品分析.md)；它们都不是第二套产品合同。Review 与 Bug 保留日期和证据，只有链接随迁移更新。来源、内容修正与未决项见[迁移映射](../features/文档归属与迁移映射.md)。
