| Feature | 范围 |
| --- | --- |
| [06｜共享独立执行服务](./06-共享独立执行服务/README.md) | 主服务与执行服务通信、受控执行、并发、取消、隔离和故障恢复 |

V1 使用共享独立执行服务，属于服务级隔离，不等于每用户或每任务独立强沙箱。当前已有本地代码与测试记录，实际部署和环境验收状态沿用 Feature 06 的证据，不因目录名称改成已验证能力。

运行合同、校验结果和候选提升条件继续引用[Feature 07](../05-产物与交付部署/07-通用源码与运行校验/README.md)，不为跨域归类复制或拆出第二份合同。用户侧文件编辑入口见[Feature 05](../03-用户交互与协作/05-项目文本文件阅读与编辑/README.md)。

平台自身的主服务、执行服务和编辑沙箱部署仍由[运行与部署](../../design/V1/技术设计/04-[工程]-运行与部署.md)维护，不与用户生成项目的交付混为一项功能。
