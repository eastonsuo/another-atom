## 已有依据

旧系统架构要求使用 Argon2id；当前 [密码实现](../../../../another_atom/domain/auth.py)使用 PBKDF2-HMAC-SHA256，迭代次数 600,000。该差异也记录在 [2026-07-12 检查](../../../review/归档/08-[综合]-2026-07-12-关键设计与实现检查.md)。这能证明实现不同，不能证明用户已批准更换算法，也不能单凭名称判断当前登录功能不可用。

[认证依赖](../../../../another_atom/api/dependencies.py)已通过服务端 Session 校验当前用户，仅测试环境允许身份头兜底。因此旧文档“生产可通过已有用户 ID 冒用”的现状描述已删除；这不等于登录限速、安全事件、迁移兼容和所有资源隔离都经过本轮验证。
