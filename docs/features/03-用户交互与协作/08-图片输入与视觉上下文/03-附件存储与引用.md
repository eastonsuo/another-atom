## 8.6 attachments

建议字段：

```text
id
user_id
project_id
session_id
file_name
mime_type
size_bytes
storage_path
status
created_at
deleted_at
```

上传流程先创建 metadata，再写入 Volume，最后将状态改为 ready。Blueprint 只能引用 ready 附件。删除操作采用软删除并异步清理文件，避免数据库已删除但文件操作失败后无法追踪。
