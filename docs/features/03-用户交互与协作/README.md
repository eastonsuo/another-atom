# 用户交互与协作

回答用户怎样表达需求、查看过程和产物、作出决定，以及直接修改内容。人工确认、文本编辑和图片理解都作为完整功能归入本域，不限于前端控件。

| Feature | 范围 |
| --- | --- |
| [01｜项目对话与交互控制](./01-项目对话与交互控制/README.md) | 常驻输入、流式呈现、活动轮次与对话恢复 |
| [03｜人工确认与流程恢复](./03-人工确认与流程恢复/README.md) | 用户审阅、精确批准、拒绝／取消、失效和恢复 |
| [05｜项目文本文件阅读与编辑](./05-项目文本文件阅读与编辑/README.md) | 文本阅读、Markdown 预览、编辑、保存与只读边界 |
| [08｜图片输入与视觉上下文](./08-图片输入与视觉上下文/README.md) | 图片添加、理解结果、失败恢复及下游复用 |
| [09｜管理员后台](./09-管理员后台/README.md) | 管理端的运营查看与角色配置；保留为独立 Feature |

人工确认定义用户决定的对象和含义，[执行编排](../02-任务规划与执行编排/README.md)负责依据有效决定推进。文件保存使用[源码与校验规则](../05-产物与交付部署/07-通用源码与运行校验/README.md)，图片进入角色上下文也不改变既有批准和验证规则。管理员后台归入管理端交互，不扩展其已有管理权限。
