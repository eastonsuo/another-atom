# 产物与交付部署

回答系统交付什么、哪些验证结果允许形成版本，以及用户怎样预览、导出和发布生成的项目。这里只组织用户项目的交付，Another Atom 平台自身的部署继续见[运行与部署](../../design/V1/技术设计/04-[工程]-运行与部署.md)。

| Feature | 范围与依据 |
| --- | --- |
| [07｜通用源码与运行校验](./07-通用源码与运行校验/README.md) | 权威源码、运行合同、验证结果与候选版本提升条件 |
| [12｜版本预览与发布](./12-版本预览与发布/README.md) | 查看与恢复版本、匹配能力的预览、导出、公开发布与更新 |

Feature 07 同时被[执行与验证环境](../04-执行与验证环境/README.md)使用。本次保持完整合同在一个位置维护；能力域只是文档归属，不改变合同由哪些组件执行。

“源码就绪”“通过真实运行验证”“可以预览”和“已经发布”不能互相替代。没有匹配运行能力的项目仍可交付源码，不自动承诺任意项目在线部署。
