# 固定串行执行｜产品说明

- Feature：11；适用版本：V1
- 整理日期：2026-09-29；复用既有固定链路，不增加执行模式
- 产品补充确认：2026-09-29，[PQ-02](./产品澄清.md#pq-02) 选择 B，V1 支持主动停止后按阶段续跑；尚待技术设计与实现
- 产品依据：[V1 固定团队执行](./03-执行交互与整体验收.md#p-63-团队负责人lead与固定团队执行)
- 交接依据：[编排器与执行状态](./02-执行状态与恢复.md#a-3-orchestrator-与执行状态)

## 背景

一次首次创建任务需要从需求形成可检查的设计、源码和验证结果。V1 采用固定顺序接力，让用户能知道当前正在做什么、前一步交付了什么，以及为什么暂时不能继续。

## 摘要

- **固定顺序**
  - 首次创建按 PM、Architect、Engineer 完整执行，再进入适用的构建、测试和校验。
- **真实交接**
  - 用户批准、上游产物和验证证据必须有效；阶段动画或模型自报不能代替这些条件。
- **按阶段续跑**
  - 主动停止后可继续同一任务，复用已完成且仍有效的阶段，从中断阶段重新执行。

## 从请求到结果

Lead 可以直接回答或澄清，也可以把明确创建请求交给团队。直接回答不创建团队执行、构建任务、Git 提交或项目版本，也不展示虚假的角色时间线；用户可显式要求调用团队。

首次创建进入团队后，依次完成产品方案、用户对当前方案的确认、架构设计、源码与测试，再由平台执行适用的验证。产品尚未批准、批准后内容改变或能力结论不支持时，不得进入架构阶段。架构和源码必须使用有效的上游依据；修复改变源码后，旧执行结果不能继续作为通过证据。

一个任务同一时刻只有一个主执行阶段。用户可以查看当前角色、阶段状态、实际产物、等待和失败原因；进度必须对应真实执行，不展示并行协作假象或模型私有推理。阶段输出应先保存，再报告完成，刷新或重连后的恢复目标沿用共同基线。

首次创建中，明确属于源码或单元测试的可修复失败最多允许一轮工程师自动修订，之后重新验证；仍失败或根因不明时停止并保留原因，不能无限返工或掩盖执行环境问题。失败重试与下文的主动停止后续跑是不同路径。

最终能否形成版本、是可运行还是仅源码就绪，由[Feature 07](../../05-产物与交付部署/07-通用源码与运行校验/01-产品说明.md)决定；没有匹配运行能力时不能伪造构建、测试或预览通过。发布不属于模型执行链，必须遵守独立发布规则。

## 主动停止与继续

V1 的首次创建和已有项目修改均支持按阶段续跑，依据为已确认的 [PQ-02](./产品澄清.md#pq-02)：

- 用户主动停止后，须先确认执行确已停止，保留原任务、已完成产物、部分可见结果与停止记录；未完成内容不能被标成已完成阶段或新版本。
- 用户点击“继续”时，继续同一任务，复用已完成且仍有效的上游阶段，从被打断的阶段重新执行，再按固定顺序推进。不是从某个输出字符、代码写入或临时进程位置接续，也不是重新创建项目。
- 首次创建尚无成功版本时，仍可复用有效的产品方案、架构等已完成阶段，不强制从头再来；产品方案尚未确认时仍须先确认，不能因续跑跳过门禁。
- 继续前重新检查当前任务依据、上游产物、批准与版本基线。不能证明有效时不强行复用；已有项目的基线、范围或批准对象变化，沿用 Feature 04 的冲突与重新确认规则，不自动跨角色回退。
- 停止完成后释放活动占用；继续仍受同一 Project 单活动执行与写入保护约束。新的独立消息不自动恢复旧任务；界面分别表达“继续原任务”和新任务输入，并展示复用阶段、重新执行阶段或不能继续的原因。

失败后的 Retry 仍在同一项目创建新 Run 并保留失败记录；等待用户补充或批准仍恢复原 Run。这两条既有规则不由主动停止后的续跑选择改写。产品上的同一任务与底层 Run、阶段尝试的关系留待技术设计明确。

## 与修改、规划和并行的关系

本功能定义首次创建的完整链路。[已有项目修改](../04-对话式代码修改/01-产品说明.md#5-lead-与下游团队如何分工)可以按已确认产品目标选择固定入口，复用有效上游结果并顺序执行剩余阶段，不能跳过批准、适用验证和版本保护。该入口选择尚未实现，技术方案和 Code Spec 仍需独立确认。

V1 不引入任意角色组合、任务图、并行执行或跨角色自动回退。先规划再按依赖执行属于后续编排范围，本次不将其变成新的 V1 承诺。

## 当前状态

共同设计已有固定三角色链路和本地验证的历史记录，实际环境验收仍依赖[执行服务](../../04-执行与验证环境/06-共享独立执行服务/01-产品说明.md)与相关交付证据。2026-09-29 已确认阶段续跑的产品目标；本次没有实现或验证该能力，不能把历史局部测试、进程重启恢复或停止接口等同于完整用户续跑。
