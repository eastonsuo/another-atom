## 后续范围

任务规划和并行不是与串行互斥的三套系统：规划确定要做什么，依赖决定能否并行，入口选择决定从哪里开始。[V2 产品草案](../../design/V2/产品设计/01-产品范围与交互.md)与[V2 编排草案](../../design/V2/技术设计/01-[Agent]-任务编排与多Agent协作.md)已有任务图、局部并行及返工设想，但尚未实现，不纳入 V1。

这次只建立已确认 V1 范围的 Feature。V2 文档仍含早期 V1 角色及审批口径，后续派生规划／并行 Feature 前需要重新核对，不能由目录整理替代范围或设计确认。
