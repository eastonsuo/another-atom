## 16. 独立候选：CC 式本地执行

该独立方向是类似 Claude Code 的本地 Agent Runtime；是否推进及其交付范围仍须单独确认，不能从云端固定执行或任务图协作推导支持：

```text
Terminal CLI
     |
     v
Local Python Agent Runtime
     |
     ├── 读取和修改本地项目文件
     ├── 执行受控 Shell / Git / npm
     ├── SQLite Session 与版本索引
     └── 启动 localhost Dev Server
                    |
                    v
             Local Visual Studio

Local Runtime ---- HTTPS ----> Cloud Auth / Quota / LLM Gateway
```

后续实现必须重新设计：

- Python/Node 安装与跨平台打包。
- 本地权限审批和工作区信任模型。
- 本地进程、端口和 Dev Server 生命周期。
- SQLite 项目如何上传、同步或发布到云端。
- 本地项目与 Cloud Project 的冲突处理。

在这些协议确定前，项目 README 和产品界面不得声称已经支持用户电脑上的本地仓库执行。现有服务端 local Git 与云端受限 Vim WebIDE 不等同于该方向。
